## Конспекты
**Git** — это локальный инструмент: все репозитории физически лежат в папках на твоём жёстком диске, а не в облаке.

Внутри одного репозитория может быть сколько угодно веток. Они не существуют сами по себе — каждая ветка либо ответвляется от другой, либо позже в неё вливается.

История проекта состоит из коммитов — это такие «точки сохранения». У каждого коммита есть свой уникальный идентификатор (hash) и комментарий, который ты пишешь сам, чтобы понимать, что именно изменилось.

Работать с Git можно не только через командную строку, но и через программы с графическим интерфейсом — например, GitHub Desktop, Sourcetree или GitKraken. Они удобны тем, кто не хочет запоминать команды.

Чтобы выложить проект на GitHub, нужно:

- Зарегистрироваться на GitHub.

- Инициализировать репозиторий в нужной папке.

- Опубликовать его — то есть связать локальный репозиторий с удалённым и залить туда файлы.
